BARATH'S MEMORY WALL

1. Open index.html in Chrome/Edge/Safari.
2. Edit the `people` array near the bottom of index.html.
3. For photos, create an `images` folder next to index.html and use:
   photo: "images/arun.jpg"
4. Change YOUR_EMAIL@example.com in sendMemory() to the email where you want memories sent.
5. Share the whole folder (or zip it).

No server/database is required for the basic version.
